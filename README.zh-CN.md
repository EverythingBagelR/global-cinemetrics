# Global Cinemetrics｜全球电影与社会变迁

**结合电影数据、历史语境与叙事表达的数字人文团队项目。**

[访问在线作品](https://globalcinemetrics.humspace.ucla.edu/) · [查看团队署名](https://globalcinemetrics.humspace.ucla.edu/about/meet-the-team/) · [English](README.md)

## 项目简介

Global Cinemetrics 通过 TMDB 与 Letterboxd 的电影数据，探讨电影类型和观众反馈随时间、地区与社会背景的变化。项目将数据可视化与历史解读结合，以公开研究网站呈现，并设有美国、全球比较及 COVID-19 影响等专题。
